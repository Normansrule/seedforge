# Code of Conduct

SeedForge is an engineering project. We want it to be a place where students, makers,
researchers and foresters can ask basic questions and report failures without embarrassment.

## Expected behaviour

* Be respectful and patient, especially with newcomers.
* Critique work and data, not people.
* Be honest about results, including negative ones. A failed build report is a contribution.
* Credit other people's work and sources.
* Respect safety and environmental boundaries described in [docs/safety.md](docs/safety.md).

## Unacceptable behaviour

* Harassment, insults, discrimination or personal attacks of any kind.
* Sharing someone's private information without permission.
* Deliberately misleading claims about validation, safety or results.
* Encouraging unsafe machine use, unauthorised seed release or untested chemical procedures.

## Scope and enforcement

This applies in all project spaces (issues, pull requests, discussions) and when representing the
project elsewhere. Report problems to the maintainers by opening a private security advisory on
GitHub (see [SECURITY.md](SECURITY.md)) or by contacting a maintainer directly. Maintainers may
edit or remove contributions and may temporarily or permanently ban participants who break this
code. Reports are handled confidentially.
