# M8 - Output storage

**Build phase:** 5  |  **Status:** experimental

## 1. Purpose

Keep finished carriers isolated and traceable so tails do not tangle.

## 2. Inputs

* accepted carriers

## 3. Outputs

* tray of carriers with IDs

## 4. Printed components

* O01 twelve-pocket tray (resize pockets to the measured dry envelope)

## 5. Purchased components

* labels

## 6. Electronics

* none

## 7. Software responsibility

* carrier ID -> tray position in carriers.csv notes

## 8. Calibration method

* measure the dry carrier envelope

## 9. Acceptance criteria

* parts remain isolated and traceable

## 10. Known risks

* pocket size is a placeholder

## 11. CAD preview

Interactive: the website module explorer loads `output_tray.glb`. Files: `hardware/cad/glb/output_tray.glb`, STEP/STL/3MF of every part in `hardware/cad/`.
