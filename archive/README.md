# Archive

Unmodified inputs, kept for provenance and traceability. **Not covered by the repository
licences** (see [LICENSE](../LICENSE)). Superseded: do not build or flash from here.

| folder | what | superseded by |
|---|---|---|
| [`eecs149-original/`](eecs149-original/ARCHIVE_NOTE.md) | the original EECS 149 group wood-winder code and local sketches | `firmware/`, `software/` |
| [`seedforge-r3-package/`](seedforge-r3-package/ARCHIVE_NOTE.md) | the supplied *SeedForge R3 RealWorld* package (docs, BOMs, wiring, controller, CAD manifests, generator, previews) | the whole repository; see [docs/project/r3-inventory.md](../docs/project/r3-inventory.md) for where each file went |

Large binary CAD from the R3 package (STEP/STL/3MF) is not duplicated here: the R3 STEP files live in
`hardware/cad/step/machine/` as the source of truth, and the meshes are regenerated from them.
