# Datasets

Licence for data in this folder: CC BY-SA 4.0 unless a sub-folder says otherwise.

```text
datasets/
  synthetic/    generated by `python -m seedforge.vision demo` (not committed; deterministic)
  raw/          unlabelled station images, one folder per run ID
  labelled/     images with a sidecar NAME.json label
  train/        split by material lot (tuning)
  validation/   split by material lot (threshold selection)
  test/         held-out material lots (reported confusion matrix only)
```

Only `README.md` placeholders are committed in `raw/`, `labelled/`, `train/`, `validation/`, `test/`:
**no real images exist yet.** The synthetic set tests the software, not the method.

## Image format

* PNG, 8-bit grey or RGB, the station camera's native resolution, no compression artefacts.
* File name: `<run_id>_<carrier_id>.png`.
* Sidecar `NAME.json`:

```json
{
  "label": "good | gap | overlap | length | deformed | tail | other",
  "run_id": "RUN-...",
  "carrier_id": "SFC-...",
  "material_lot": "...",
  "recipe": "paper_reference",
  "px_per_mm": 40.0,
  "measured": {"length_mm": 38.7, "turns": 7, "max_gap_mm": 0.5, "notes": "calipers + microscope"},
  "labeller": "initials",
  "date": "YYYY-MM-DD"
}
```

Labels come from **measurement of the coil**, made independently of the pipeline's verdict.

## Splits

Split by material lot, never randomly: images of one lot must not appear in both tuning and test
sets. Record the split in `splits.csv` (`file,split,material_lot`).

## Privacy

Station images should contain only the coil and fixtures. Do not commit images showing people.
